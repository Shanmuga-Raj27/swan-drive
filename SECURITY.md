# Security Policy

## Project Status

Swan Drive is an experimental, open-source learning project currently in beta and under active development and testing.

The project is provided for learning, experimentation, and demonstration purposes. Features and security measures may change as development progresses.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Swan Drive, please report it responsibly.

**Security Contact:** rshanmugaraj11@gmail.com

You can send your security report directly to the email address above.

Alternatively, you can use GitHub's [Private Vulnerability Reporting](../../security/advisories/new) feature to submit a report confidentially.

Please do not disclose security vulnerabilities through public GitHub Issues, Discussions, or Pull Requests.

## What to Include in Your Report

To help investigate the issue, please include:

- A clear description of the vulnerability.
- The affected component or feature.
- Steps to reproduce the issue.
- Potential security impact.
- Proof of concept or supporting evidence, if available.

Please avoid including real user data, passwords, API keys, access tokens, or other sensitive information in your report.

## Response and Disclosure

Every report will be reviewed and investigated based on its severity and available resources.

You will receive an update after the initial review when reasonably possible. Investigation and remediation timelines may vary depending on the complexity of the issue.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

We appreciate responsible security research and the efforts of everyone helping make Swan Drive safer.
